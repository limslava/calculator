- Смешивание бизнес-логики с UI-логикой
- Отсутствие типизации
- Ограниченная масштабируемость

## 2. Текущие проблемы

### 2.1. Архитектурные проблемы
- Глобальное состояние через `window.database`
- Отсутствие разделения на слои (presentation, business, data)
- Длинные файлы с смешанной ответственностью
- Отсутствие dependency injection

### 2.2. Технические проблемы
- Отсутствие автоматического тестирования
- Хранение данных в JSON файлах
- Отсутствие типизации (TypeScript)
- Синхронная обработка больших файлов
- Отсутствие кеширования результатов расчетов

### 2.3. UX/UI проблемы
- Отсутствие валидации форм на клиенте
- Нет индикации загрузки при длительных операциях
- Интерфейс тормозит при больших объемах данных
- Отсутствие обработки ошибок на UI уровне
