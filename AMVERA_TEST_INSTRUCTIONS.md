# Инструкции по тестированию на Amvera

## Проблема
Ошибка 503 - контейнеры приложения не могут запуститься из-за ошибки.

## Решение для тестирования

### Вариант 1: Использовать тестовую конфигурацию
1. Переименуйте файлы:
   - `amvera.test.yml` → `amvera.yml`
   - `Dockerfile.test` → `Dockerfile`

2. Запустите деплой на Amvera

### Вариант 2: Проверить текущую конфигурацию
1. Убедитесь, что используется тариф "Начальный" или выше
2. Проверьте логи приложения в панели управления Amvera
3. Если проблема в ресурсах - временно перейдите на старший тариф

### Вариант 3: Упрощенное приложение
Тестовое приложение `test-server.js` содержит только базовый функционал:
- Healthcheck endpoint `/health`
- Простой маршрут `/`
- Минимальные зависимости

## Рекомендации

1. **Тариф**: Используйте тариф "Начальный" или выше для тестирования
2. **Логи**: Проверьте логи приложения в панели Amvera для выявления конкретных ошибок
3. **Ресурсы**: Если приложение падает с SIGTERM - возможно не хватает памяти

## Следующие шаги

1. Попробуйте тестовую конфигурацию
2. Проверьте логи на Amvera
3. Если тестовая версия работает - постепенно добавляйте функционал обратно
4. Если не работает - обратитесь в поддержку support@amvera.ru с логами
