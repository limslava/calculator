Тест исправления авторизации

Проблема

Скрипт пытался загружать данные с сервера до авторизации пользователя, что вызывало ошибки 401 (Unauthorized).

GET https://calculator-limslava.amvera.io/api/data/sea 401 (Unauthorized)

Исправления

  • ✅ Убрана автоматическая загрузка данных при инициализации страницы
  • ✅ Добавлена проверка авторизации в функции loadDatabaseData()
  • ✅ Добавлена функция loadLocalDataOnly() для загрузки только локальных данных
  • ✅ Обновлена функция setupCalculator() для проверки авторизации
  • ✅ Данные загружаются только после выбора роли или базы данных

Логика работы после исправления

  1. Страница загружается → НЕ загружает данные с сервера
  2. Пользователь авторизуется → Загружаются данные с сервера
  3. Если авторизация не пройдена → Загружаются только локальные данные
  4. При выборе базы данных → Загружаются данные с сервера (если авторизован)

Проверка в консоли браузера

Откройте консоль разработчика (F12) и проверьте:

// Должны видеть: ✅ Приложение логистики инициализировано ⏳ Ожидание авторизации для загрузки данных с сервера ✅ Курс ЦБ РФ загружен: 1 USD = ... RUB // НЕ должны видеть: ❌ Ошибка загрузки данных с сервера для sea: Error: HTTP error! status: 401
