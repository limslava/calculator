## 🎯 ОСНОВНЫЕ ФУНКЦИОНАЛЬНЫЕ КОМПОНЕНТЫ

### 1. РОЛИ ПОЛЬЗОВАТЕЛЕЙ
- **Закупщик**: Загрузка баз данных из Excel файлов
- **Менеджер по продажам**: Расчет ставок для клиентов

### 2. ТИПЫ БАЗ ДАННЫХ
- **Море**: Морские перевозки
- **ЖД**: Железнодорожные перевозки  
- **Прямое ЖД**: Прямые железнодорожные перевозки
- **Прямое море**: Прямые морские перевозки

### 3. ТИПЫ РАСЧЕТА
- **Отдельные ставки**: Расчет по отдельным типам перевозок
- **Комплексный расчет**: Расчет всех доступных ставок по маршруту

### 4. КЛЮЧЕВЫЕ ФУНКЦИИ В SCRIPT.JS

#### Глобальные переменные:
- `currentRole` - текущая роль пользователя
- `currentDatabase` - выбранная база данных
- `currentCalculationType` - тип расчета (separate/complex)
- `usdToRubRate` - курс ЦБ РФ
- `is20ftOver24Tons` - флаг весовой категории 20-футовых контейнеров
- `isVTTTrigger` - флаг триггера ВТТ

#### Основные функции:
- `normalizeCityName()` - нормализация названий городов
- `calculateAllRates()` - расчет всех типов ставок
- `displayComplexResults()` - отображение результатов комплексных ставок
- `setupComplexAutocomplete()` - настройка автозаполнения для комплексных ставок
- `updateContainerTypesForComplex()` - обновление типов контейнеров для комплексных ставок

### 5. ЛОГИКА КОМПЛЕКСНЫХ СТАВОК (МОРЕ + ЖД)

#### Базовые правила соединения:
1. `seaItem.pol` = выбранный пользователем пункт отправления
2. `seaItem.city` = `railItem.city` (город моря = город жд)
3. `seaItem.dropOffArea` = `railItem.destination` (зона выгрузки моря = пункт назначения жд)
4. `railItem.destination` = выбранный пользователем пункт назначения

#### Дополнительные правила:
- **Триггер веса**: `is20ftOver24Tons` - выбор ставки для 20-футовых контейнеров
- **Триггер ВТТ**: `isVTTTrigger` - дополнительное правило: `seaItem.pod` = `railItem.agent`

### 6. НОРМАЛИЗАЦИЯ НАЗВАНИЙ ГОРОДОВ
- **Санкт-Петербург**: SPB, St.Petersburg, STP, St. petersburg, Saint Petersburg → "St. Petersburg"
- **Тольятти**: Тольятти, Tolyatti → "Tolyatti"
- **Москва**: MOW, MSK → "Moscow"

### 7. СИНХРОНИЗАЦИЯ ТИПОВ КОНТЕЙНЕРОВ
- **20'DC** → `container20Under24` (без галочки) или `container20Over24` (с галочкой)
- **40'HC** → `container40`

### 8. ХРАНЕНИЕ ДАННЫХ
- Локальное хранилище браузера (localStorage)
- Базы данных: `logistics_db_sea`, `logistics_db_rail`, `logistics_db_direct_rail`, `logistics_db_direct_sea`

### 9. СЕРВЕРНЫЕ ФУНКЦИИ
- Прокси-маршрут для парсинга курса ЦБ РФ
- Обход CSP ограничений браузера

## 🚀 ЗАПУСК ПРОЕКТА
1. Установить зависимости: `npm install`
2. Запустить сервер: `node server.js`
3. Открыть в браузере: `http://localhost:3000`
