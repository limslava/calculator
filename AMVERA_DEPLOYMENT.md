# Развертывание на Amvera

## Настройка переменных окружения

В панели управления Amvera необходимо настроить следующие переменные окружения:

### Обязательные переменные
```
DATABASE_URL=postgresql://amvera-limslava-cnpg-postgresql-calcul-rw
NODE_ENV=production
PORT=3000
JWT_SECRET=your-very-secure-jwt-secret-key-here
```

### Рекомендуемые переменные
```
LOG_LEVEL=info
CORS_ORIGIN=*
```

## Конфигурация базы данных

Приложение автоматически:
- Создает необходимые таблицы при первом запуске
- Инициализирует администратора (логин: `admin`, пароль: `admin123`)
- Загружает начальные данные

## Мониторинг

После развертывания проверьте:
1. Логи приложения на наличие ошибок подключения к базе данных
2. Доступность приложения по URL
3. Функциональность авторизации
4. Загрузку данных в интерфейсе продаж

## Устранение неполадок

### Ошибка подключения к базе данных
- Проверьте корректность DATABASE_URL
- Убедитесь, что база данных доступна из сети Amvera
- Проверьте настройки SSL

### Ошибка авторизации
- Проверьте JWT_SECRET переменную
- Убедитесь, что она достаточно длинная и безопасная

### Предупреждение "Тип данных complex не загружается"
Это нормальное поведение - комплексные расчеты динамически вычисляются и не хранятся в базе данных.
