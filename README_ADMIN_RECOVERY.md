# Восстановление администратора

## Проблема
После исправления кнопки "Назад" администраторская учетная запись `admin@logistics.com` стала определяться как менеджер по продажам (sales) вместо администратора.

## Решение

### Способ 1: Использование страницы сброса (рекомендуется)

1. Откройте файл [`reset-admin.html`](reset-admin.html) в браузере
2. Нажмите кнопку "Сбросить администратора"
3. После успешного сброса перейдите к основному приложению [`index.html`](index.html)
4. Войдите с данными:
   - **Логин**: `admin@logistics.com`
   - **Пароль**: `admin123`
   - **Роль**: Администратор

### Способ 2: Ручной сброс через консоль браузера

1. Откройте основное приложение [`index.html`](index.html)
2. Откройте консоль разработчика (F12 → Console)
3. Выполните следующие команды:

```javascript
// Очистка localStorage
localStorage.removeItem('logistics_users');
localStorage.removeItem('current_user');
localStorage.removeItem('sent_emails');

// Создание администратора
const adminUser = {
    id: Date.now().toString(),
    email: 'admin@logistics.com',
    role: 'admin',
    password: btoa('admin123'),
    isActive: true,
    createdAt: new Date().toISOString(),
    lastLogin: null
};

const users = [adminUser];
localStorage.setItem('logistics_users', JSON.stringify(users));

console.log('✅ Администратор восстановлен');
console.log('Логин: admin@logistics.com');
console.log('Пароль: admin123');
```

4. Обновите страницу и войдите с новыми данными

## Проверка восстановления

После восстановления администратора проверьте:

1. Войдите как `admin@logistics.com` / `admin123`
2. Должна отобразиться **панель администратора** с возможностью управления пользователями
3. В консоли браузера должны быть сообщения:
   - `✅ Пользователь авторизован: admin@logistics.com`
   - `🔧 Роль пользователя: admin`
   - `✅ Показана панель администратора`

## Причина проблемы

Проблема возникла из-за конфликта между локальной переменной `currentRole` в [`script.js`](script.js) и глобальной переменной `window.currentRole` в [`auth-ui.js`](auth-ui.js). При исправлении кнопки "Назад" произошло изменение логики работы с ролями, что привело к неправильному определению роли администратора.

## Предотвращение в будущем

Система теперь включает дополнительные проверки:
- Проверка наличия администратора при загрузке пользователей
- Детальное логирование ролей при аутентификации
- Автоматическое создание администратора при его отсутствии

## Технические детали

- **Файл аутентификации**: [`auth.js`](auth.js) - содержит логику создания и проверки пользователей
- **Интерфейс аутентификации**: [`auth-ui.js`](auth-ui.js) - управляет отображением интерфейсов по ролям
- **Основной скрипт**: [`script.js`](script.js) - содержит логику навигации и кнопки "Назад"

Если проблема повторится, используйте страницу [`reset-admin.html`](reset-admin.html) для быстрого восстановления.
