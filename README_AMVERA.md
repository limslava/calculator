# Развертывание калькулятора логистики на Amvera

Это руководство поможет вам развернуть приложение калькулятора логистики на платформе Amvera.

## Предварительные требования

- Аккаунт на [Amvera](https://cloud.amvera.ru)
- GitHub репозиторий с кодом приложения
- Docker (для локального тестирования)

## Структура проекта

```
├── amvera.yml          # Конфигурация Amvera
├── Dockerfile          # Docker образ
├── server.js           # Node.js сервер
├── package.json        # Зависимости Node.js
├── index.html          # Главная страница
├── script.js           # Клиентский JavaScript
├── styles.css          # Стили
├── utils.js            # Утилиты
├── modules/            # Модули для разных типов перевозок
├── templates/          # Шаблоны Excel
└── .github/workflows/  # GitHub Actions для CI/CD
```

## Конфигурация Amvera

Приложение настроено для работы на порту **3000** с следующими характеристиками:
- **Память**: 512 MiB
- **CPU**: 500m
- **Healthcheck**: автоматическая проверка доступности

## Инструкция по развертыванию

### 1. Подготовка репозитория

Убедитесь, что все файлы закоммичены и отправлены в GitHub:

```bash
git add .
git commit -m "Подготовка к развертыванию на Amvera"
git push origin main
```

### 2. Создание проекта на Amvera

1. Перейдите на [Amvera Cloud](https://cloud.amvera.ru)
2. Нажмите "Создать проект"
3. Выберите "Из Git репозитория"
4. Укажите URL вашего GitHub репозитория
5. Назовите проект (например, `logistics-calculator`)

### 3. Настройка проекта

Amvera автоматически обнаружит конфигурационные файлы:
- `amvera.yml` - основная конфигурация
- `Dockerfile` - сборка Docker образа

### 4. Запуск развертывания

После настройки Amvera автоматически:
- Соберет Docker образ из вашего репозитория
- Развернет приложение на платформе
- Настроит доменное имя (например: `https://logistics-calculator.amvera.io`)

### 5. Проверка развертывания

После успешного развертывания:
1. Откройте URL вашего приложения
2. Убедитесь, что калькулятор работает корректно
3. Проверьте функциональность получения курса ЦБ РФ

## Локальное тестирование

Перед развертыванием можно протестировать приложение локально:

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Или через Docker
docker build -t logistics-calculator .
docker run -p 3000:3000 logistics-calculator
```

## Особенности приложения

- **SPA (Single Page Application)** - все маршруты обслуживаются через index.html
- **Безопасность** - настроены CSP заголовки через Helmet
- **Сжатие** - включено сжатие Gzip через compression middleware
- **Курс ЦБ РФ** - автоматическое получение курса USD через API

## Мониторинг и логи

После развертывания вы можете:
- Просматривать логи приложения в панели управления Amvera
- Мониторить состояние healthcheck
- Настраивать масштабирование при необходимости

## Обновление приложения

Для обновления приложения просто отправьте изменения в ветку `main` вашего репозитория. Amvera автоматически пересоберет и переразвернет приложение.

## Устранение неполадок

Если приложение не запускается:
1. Проверьте логи в панели Amvera
2. Убедитесь, что порт 3000 правильно настроен
3. Проверьте корректность `amvera.yml` и `Dockerfile`

## Контакты

При возникновении проблем с развертыванием обратитесь к документации Amvera или создайте issue в репозитории проекта.
