# Калькулятор ставок в логистике

Веб-приложение для расчета логистических ставок с модульной архитектурой.

## Структура проекта

```
Khasan/
├── index.html              # Главная страница приложения
├── script.js               # Основная логика приложения
├── utils.js                # Утилиты для парсинга данных и работы с интерфейсом
├── styles.css              # Стили и адаптивный дизайн
├── server.js               # Express сервер
├── package.json            # Зависимости проекта
├── Dockerfile              # Конфигурация Docker
├── amvera.yml              # Конфигурация для Amvera
├── .dockerignore           # Исключения для Docker
├── .gitignore              # Исключения для Git
│
├── modules/                # Модули для разных типов перевозок
│   ├── direct-rail.js      # Модуль для прямых железнодорожных перевозок
│   ├── direct-sea.js       # Модуль для прямых морских перевозок
│   ├── sea.js              # Модуль для морских перевозок
│   └── rail.js             # Модуль для железнодорожных перевозок (не прямых)
│
├── templates/              # Шаблоны Excel файлов
│   ├── template-direct-rail.xlsx
│   ├── template-direct-sea.xlsx
│   ├── template-sea.xlsx
│   └── template-rail.xlsx
│
├── docs/                   # Документация
│   ├── AMVERA_DEPLOYMENT_GUIDE.md
│   ├── DEPLOYMENT.md
│   └── README_DEPLOYMENT.md
│
└── .github/workflows/      # GitHub Actions
    └── deploy-amvera.yml
```

## Функциональность

### Роли пользователей
- **Закупщик** - загрузка базы данных из Excel файлов
- **Менеджер по продажам** - расчет ставок для клиентов

### Типы перевозок
1. **Морские перевозки** - расчет ставок для морских контейнерных перевозок
2. **Железнодорожные перевозки** - расчет ставок для ЖД перевозок
3. **Прямые ЖД перевозки** - расчет ставок для прямых железнодорожных перевозок
4. **Прямые морские перевозки** - расчет ставок для прямых морских перевозок
5. **Море + ЖД** - комбинированные перевозки

### Основные возможности
- Загрузка данных из Excel файлов
- Автоматический расчет ставок при заполнении полей
- Каскадная фильтрация данных
- Автопоиск и подсказки в выпадающих списках
- Сортировка результатов от меньшей к большей ставке
- Адаптивный дизайн для мобильных устройств
- Хранение данных в localStorage

## Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Библиотеки**: XLSX.js для работы с Excel файлами
- **Стили**: CSS Grid, Flexbox, адаптивный дизайн
- **Хранение данных**: localStorage

## Установка и запуск

### Локальная разработка
```bash
npm install
npm start
```

Приложение будет доступно по адресу: http://localhost:3001

### Docker
```bash
docker build -t logistics-calculator .
docker run -p 3001:3001 logistics-calculator
```

## Развертывание

Проект поддерживает развертывание на различных платформах:
- **Amvera** - через GitHub Actions
- **Docker** - контейнеризация приложения
- **Любой хостинг** с поддержкой Node.js

Подробные инструкции по развертыванию смотрите в папке `docs/`.
