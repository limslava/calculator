## Функциональность

### Роли пользователей
- **Закупщик** - загрузка базы данных из Excel файлов и управление тарифными ставками
- **Менеджер по продажам** - расчет ставок для клиентов

### Типы перевозок
1. **Морские перевозки** - расчет ставок для морских контейнерных перевозок
2. **Железнодорожные перевозки** - расчет ставок для ЖД перевозок
3. **Прямые ЖД перевозки** - расчет ставок для прямых железнодорожных перевозок
4. **Прямые морские перевозки** - расчет ставок для прямых морских перевозок
5. **Море + ЖД** - комбинированные перевозки
6. **Тарифные ставки** - управление дополнительными тарифами (только для закупщика)

### Основные возможности
- Загрузка данных из Excel файлов
- Автоматический расчет ставок при заполнении полей
- Каскадная фильтрация данных
- Автопоиск и подсказки в выпадающих списках
- Сортировка результатов от меньшей к большей ставке
- **Модальное окно для расчета маржинальности** - двойной клик по результату
- Расчет комплексных ставок "Море + ЖД" с правилами соединения
- **Тарифные ставки** - управление дополнительными тарифами (ВТТ, ПРР, Автовывоз)
- **Триггер ВТТ** - автоматическое добавление стоимости ВТТ к комплексным ставкам
- Автоматическая конвертация валют (USD/RUB) по курсу ЦБ РФ
- Адаптивный дизайн для мобильных устройств
- Хранение данных в localStorage

## Тарифные ставки и ВТТ

### Управление тарифами (только для закупщика)
- **ВТТ** - стоимость ВТТ в российских рублях
- **ПРР 20** - стоимость ПРР для 20-футовых контейнеров
- **ПРР 40** - стоимость ПРР для 40-футовых контейнеров
- **Автовывоз 20** - стоимость автовывоза для 20-футовых контейнеров
- **Автовывоз 40** - стоимость автовывоза для 40-футовых контейнеров

### Триггер ВТТ в комплексных ставках
- **Активация**: чекбокс "ВТТ (море POD = жд агент)" в комплексном расчете
- **Условия**: автоматически добавляет стоимость ВТТ к комплексным ставкам Море+ЖД
- **Логика**: применяется только при совпадении "море POD = жд агент" и "Тыловой Терминал = нет"
- **Отображение**: ВТТ отображается как отдельная позиция в модальных окнах себестоимости и накрутки

## Модальное окно для расчета маржинальности

### Функциональность
- **Открытие**: двойной клик по любой строке в результатах расчета
- **Себестоимость**: отображает базовую ставку в зависимости от типа перевозки
- **Накрутка**: поля для ввода накрутки в соответствующей валюте
- **Результат**: итоговые ставки с накруткой (без отображения самой накрутки)
- **Копирование**: кнопка для копирования результатов в буфер обмена
- **ВТТ**: отображается как отдельная позиция при включенном триггере ВТТ

### Типы перевозок в модальном окне

#### Прямое море / Море
- **Себестоимость**: "Стоимость фрахта"
- **Накрутка**: поле для ввода в USD
- **Результат**: "Стоимость фрахта с накруткой"

#### Прямое ЖД / ЖД
- **Себестоимость**: "Стоимость ЖД перевозки"
- **Накрутка**: поле для ввода в USD/RUB
- **Результат**: "Стоимость ЖД перевозки с накруткой"

#### Море + ЖД (комплексные ставки)
- **Себестоимость**: "Стоимость фрахта" и "Стоимость ЖД перевозки" и "Общая стоимость"
- **Накрутка**: отдельные поля для моря (USD) и ЖД (RUB)
- **Результат**: "Стоимость фрахта с накруткой", "Стоимость ЖД перевозки с накруткой" и "Общая стоимость с накруткой"

## Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Библиотеки**: XLSX.js для работы с Excel файлами
- **Стили**: CSS Grid, Flexbox, адаптивный дизайн
- **Хранение данных**: localStorage

## Установка и запуск

### Локальная разработка
```bash
npm install
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

### Docker
```bash
docker build -t logistics-calculator .
docker run -p 3000:3000 logistics-calculator
```

## Развертывание на Amvera

Проект полностью готов к развертыванию на платформе Amvera через GitHub:

### Быстрый старт
1. Отправьте код в GitHub репозиторий
2. Создайте проект на [Amvera](https://cloud.amvera.ru)
3. Выберите "Из Git репозитория"
4. Укажите URL вашего репозитория
5. Amvera автоматически развернет приложение

### Подробные инструкции
Смотрите [README_AMVERA.md](README_AMVERA.md) для полного руководства по развертыванию.

### Автоматическое развертывание
При пуше в ветку `main` GitHub Actions автоматически:
- Собирает и тестирует Docker образ
- Проверяет работоспособность приложения
- Готовит приложение к развертыванию

После развертывания приложение будет доступно по адресу: `https://[имя-проекта].amvera.io`
