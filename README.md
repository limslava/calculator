# 🚢 Система расчета логистических ставок

Профессиональная система для управления логистическими ставками, расчета стоимости перевозок и управления пользователями.

## 📋 О проекте

Система предназначена для автоматизации расчета стоимости логистических перевозок с поддержкой различных типов транспорта:
- **Морские перевозки** (прямые и комплексные)
- **Железнодорожные перевозки** (прямые и комплексные)
- **Комплексные перевозки** (море + железная дорога)

## 📊 Базы данных

Система работает с несколькими типами баз данных:
- **sea** - Морские перевозки
- **rail** - Железнодорожные перевозки
- **direct_sea** - Прямые морские перевозки
- **direct_rail** - Прямые железнодорожные перевозки
- **tariff** - Тарифы и дополнительные услуги

## 🔄 API Endpoints

### Данные
- `GET /api/data/{type}` - Получить данные по типу
- `POST /api/data/{type}` - Сохранить данные

### Аутентификация
- `POST /api/auth/login` - Вход в систему
- `POST /api/auth/logout` - Выход из системы

### Курсы валют
- `GET /api/exchange-rate` - Получить курс ЦБ РФ

## 🐛 Решенные проблемы

✅ **Исправлена навигация между интерфейсами:**
- Кнопки "Закупщик" и "Менеджер по продажам" теперь открывают интерфейсы в текущей вкладке
- Администратор сохраняет свою роль при переходе между интерфейсами
- Корректный возврат на главную страницу при выходе

✅ **Исправлена система авторизации:**
- Автоматическое перенаправление пользователей на соответствующие интерфейсы после входа
- Пользователи с ролью "sales" автоматически перенаправляются на `interfaces/sales-interface.html`
- Пользователи с ролью "purchaser" автоматически перенаправляются на `interfaces/purchaser-interface.html`
- Отдельные интерфейсы проверяют авторизацию при загрузке
- Обновлены пути перенаправления после реорганизации структуры проекта
