# Калькулятор ставок в логистике

Веб-приложение для расчета ставок в логистике с поддержкой различных типов перевозок.

## Функциональность

### Роли пользователей

1. **Закупщик** - загружает базу данных из Excel файлов
2. **Менеджер по продажам** - использует калькулятор для расчета ставок

### Типы баз данных

- **Море** - Морские перевозки
- **ЖД** - Железнодорожные перевозки  
- **Прямое ЖД** - Прямые железнодорожные перевозки
- **Прямое море** - Прямые морские перевозки
- **Море + ЖД** - Комбинированные перевозки

## Структура данных для морских перевозок

Для загрузки Excel файлов используется следующая структура данных:

| Поле | Описание | Тип |
|------|-----------|-----|
| Date of validity | Дата действия ставки | Дата |
| Agent | Агент | Текст |
| Carrier | Перевозчик | Текст |
| POL | Port of Loading | Текст |
| POD | Port of Discharge | Текст |
| City | Город назначения | Текст |
| Transit port | Транзитный порт | Текст |
| DROP OFF AREA VIA VVO | Зона выгрузки через ВВО | Текст |
| SOC 20/40 | Ставки для SOC контейнеров 20' и 40' | Число (2 значения) |
| 20'DC FILO | Ставки для 20'DC контейнеров (легкая/тяжелая) | Число (2 значения) |
| 40'HC FILO | Ставка для 40'HC контейнера | Число |
| Конвертация | Валюта | Текст |
| ETD | Estimated Time of Departure | Дата |
| Remarks | Примечания | Текст |

## Установка и запуск

1. Скопируйте все файлы в одну папку
2. Откройте файл `index.html` в браузере
3. Приложение готово к использованию

## Использование

### Для закупщика:

1. Выберите роль "Закупщик"
2. Выберите тип базы данных (например, "Море")
3. Загрузите Excel файл с данными
4. Просмотрите предпросмотр данных
5. Сохраните данные в базу

### Для менеджера по продажам:

1. Выберите роль "Менеджер по продажам"
2. Выберите тип базы данных
3. Заполните параметры поиска:
   - POL (Port of Loading)
   - POD (Port of Discharge) 
   - Город назначения (опционально)
   - Тип контейнера
4. Нажмите "Рассчитать ставки"
5. Просмотрите результаты расчета

## Типы контейнеров

- **SOC 20'** - Shipper's Own Container 20 футов
- **SOC 40'** - Shipper's Own Container 40 футов
- **20'DC FILO (легкий)** - 20ft Dry Container Free In/Liner Out (легкий груз)
- **20'DC FILO (тяжелый)** - 20ft Dry Container Free In/Liner Out (тяжелый груз)
- **40'HC FILO** - 40ft High Cube Container Free In/Liner Out

## Технические особенности

- Данные сохраняются в localStorage браузера
- Поддержка русского языка
- Адаптивный дизайн для мобильных устройств
- Валидация вводимых данных

## Демонстрационные данные

Приложение включает генератор тестовых данных для демонстрации функциональности.
