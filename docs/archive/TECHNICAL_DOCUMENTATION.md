# 📚 Техническая документация

## Архитектура приложения

### Общая структура
Приложение представляет собой SPA (Single Page Application) на Node.js с клиентской частью на чистом JavaScript и серверной частью на PostgreSQL.

### Компоненты системы

#### Серверная часть
- **Node.js + Express** - сервер для обслуживания статических файлов и API
- **PostgreSQL + Sequelize ORM** - реляционная база данных для хранения всех данных
- **JWT аутентификация** - безопасная система авторизации
- **Helmet** - настройки безопасности заголовков
- **Compression** - сжатие данных Gzip
- **Content Security Policy** - политика безопасности контента

#### Клиентская часть
- **HTML/CSS/JavaScript** - чистый фронтенд без фреймворков
- **SheetJS (XLSX)** - обработка Excel файлов
- **localStorage** - хранение сессий и резервных копий
- **Fetch API** - взаимодействие с серверными API
- **JWT токены** - авторизованные запросы к серверу

#### Модули расчета
- **Морские перевозки** ([`sea.js`](sea.js:1))
- **Железнодорожные перевозки** ([`rail.js`](rail.js:1))
- **Прямые морские перевозки** ([`direct-sea.js`](direct-sea.js:1))
- **Прямые ЖД перевозки** ([`direct-rail.js`](direct-rail.js:1))
- **Комплексные расчеты** - динамические вычисления на основе других типов

## Функциональность

### Роли пользователей
- **Администратор** - полный доступ, управление пользователями
- **Менеджер по закупкам** - доступ к интерфейсу закупок
- **Менеджер по продажам** - доступ к интерфейсу продаж

### Типы перевозок
1. **Море** - морские контейнерные перевозки
2. **ЖД** - железнодорожные перевозки
3. **Прямое ЖД** - прямые железнодорожные перевозки
4. **Прямое море** - прямые морские перевозки
5. **Море+ЖД** - комбинированные перевозки (комплексные расчеты)

### Особенности комплексных расчетов
Комплексные расчеты (тип 'complex') имеют особую архитектуру:

#### Хранение данных
- **Не хранятся в базе данных** - данные вычисляются динамически
- **Сообщение в логах**: "⚠️ Тип данных 'complex' не загружается из базы данных (комплексный расчет)" - это нормальное поведение
- **Динамическое вычисление** - ставки рассчитываются на основе данных из других типов

#### Логика соединения
- **Морская часть** - данные из таблиц `sea` и `direct_sea`
- **Железнодорожная часть** - данные из таблиц `rail` и `direct_rail`
- **Автоматическое соединение** - система находит связанные маршруты по городам и портам
- **Конвертация валют** - морские ставки в USD конвертируются в RUB для сложения с ЖД ставками

#### API обработка
- **Сервер**: возвращает пустой массив для типа 'complex' с информационным сообщением
- **Клиент**: не пытается загружать данные для 'complex' из базы
- **Расчет**: выполняется динамически на клиентской стороне

### Формат данных
- **Excel файлы** с определенной структурой столбцов
- **Автоматический поиск** по параметрам перевозки
- **Расчет ставок** на основе загруженных данных

### Тарифы для агентов (Сверхнормативное пользование)
Система поддерживает загрузку тарифов агентов для расчета сверхнормативного пользования (СНП):

#### Функциональность
- **Загрузка из Excel** - поддержка файлов с колонками: Carrier, POD, DROP OFF AREA VIA VVO, СНП
- **Парсинг данных** - функция `Utils.parseAgentTariffData()` для обработки Excel файлов
- **Автоматическое добавление timestamp** - при загрузке данных автоматически добавляется поле timestamp
- **Интеграция с поиском** - данные используются в модуле поиска СНП для менеджера по продажам
- **Предпросмотр данных** - отображение загруженных тарифов с корректным форматированием дат

#### Структура данных
```javascript
{
  "carrier": "Название перевозчика",
  "pod": "Порт назначения",
  "dropOffArea": "Зона выгрузки через ВВО",
  "snp": "Сверхнормативное пользование",
  "timestamp": "2026-01-12T01:40:30.924Z"
}
```

#### Интерфейс
- **Раздел "Тарифы для агентов"** в интерфейсе менеджера по закупкам
- **Загрузка через Excel** - основной способ добавления данных
- **Удаление лишних элементов** - удалены блоки с инструкциями и кнопка "Сохранить тарифы агентов"
- **Корректное отображение дат** - исправлена проблема с "Invalid Date" в столбце "Обновлено"

### Сервер ([`server.js`](server.js:1))
```javascript
const express = require('express');
const helmet = require('helmet');
const compression = require('compression');
const path = require('path');

const app = express();
const PORT = process.env.PORT || 3001;

// Middleware безопасности
app.use(helmet({
    contentSecurityPolicy: {
        directives: {
            defaultSrc: ["'self'"],
            scriptSrc: ["'self'", "'unsafe-inline'"],
            styleSrc: ["'self'", "'unsafe-inline'"],
            imgSrc: ["'self'", "data:", "https:"],
            connectSrc: ["'self'", "https://www.cbr-xml-daily.ru"]
        }
    }
}));

app.use(compression());
app.use(express.static(path.join(__dirname)));

app.listen(PORT, () => {
    console.log(`🚀 Сервер запущен на порту ${PORT}`);
});
```

## API интеграции

### Курс ЦБ РФ
Приложение автоматически получает курс USD через публичное API:

```javascript
async function getExchangeRate() {
    try {
        const response = await fetch('https://www.cbr-xml-daily.ru/daily_json.js');
        const data = await response.json();
        return data.Valute.USD.Value;
    } catch (error) {
        console.error('Ошибка получения курса:', error);
        return 90; // Значение по умолчанию
    }
}
```

## Хранение данных

### PostgreSQL структура
Система использует PostgreSQL для хранения всех данных с моделями Sequelize:

#### Модели данных
- **User** - пользователи системы с ролями и JWT аутентификацией
- **SeaData** - данные морских перевозок (JSONB поле)
- **RailData** - данные железнодорожных перевозок (JSONB поле)
- **DirectRailData** - данные прямых железнодорожных перевозок (JSONB поле)
- **DirectSeaData** - данные прямых морских перевозок (JSONB поле)
- **TariffData** - тарифы и дополнительные услуги (JSONB поле)

#### Особенности хранения
- **JSONB поля** - данные логистики хранятся в формате JSONB для гибкости
- **Автоматическое обновление** - время последнего обновления отслеживается автоматически
- **Подсчет записей** - количество записей сохраняется для быстрого доступа
- **Резервное копирование** - автоматическое создание резервных копий в localStorage

## Устранение неполадок

### Частые проблемы
1. **Не загружаются Excel файлы** - проверьте структуру файла
2. **Не работает расчет** - проверьте наличие данных в localStorage
3. **Ошибка авторизации** - используйте страницу сброса администратора
4. **Не приходят email** - проверьте настройки SMTP

### Отладка
Используйте консоль разработчика (F12) для просмотра логов и проверки данных в localStorage.
