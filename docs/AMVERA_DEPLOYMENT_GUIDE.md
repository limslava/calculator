# Пошаговая инструкция по развертыванию на Amvera

## Шаг 1: Создание проекта в Amvera

1. **Перейдите в Amvera Console:**
   - https://cloud.amvera.ru
   - Авторизуйтесь в системе

2. **Создайте новый проект:**
   - Нажмите "Создать проект"
   - **ВЫБЕРИТЕ: "Приложение"** (Application)
   - Это правильный выбор для нашего Node.js веб-приложения

3. **Настройте подключение к Git:**
   - Выберите "Из Git репозитория"
   - Укажите URL: `https://github.com/limslava/calculator`
   - Нажмите "Подключить"

## Шаг 2: Настройка приложения

После подключения репозитория:

1. **Amvera автоматически обнаружит конфигурацию:**
   - Файл [`amvera.yml`](amvera.yml:1) будет автоматически прочитан
   - Настройки портов, ресурсов и окружения применятся

2. **Проверьте настройки:**
   - **Порт:** 3001 (внутренний), 3000 (внешний)
   - **Память:** 512Mi
   - **CPU:** 500m
   - **Окружение:** NODE_ENV=production

## Шаг 3: Запуск развертывания

1. **Запустите развертывание:**
   - Нажмите "Deploy" или "Развернуть"
   - Дождитесь завершения процесса сборки

2. **Мониторинг процесса:**
   - Следите за логами сборки
   - Убедитесь, что все шаги завершены успешно

## Шаг 4: Проверка работоспособности

После успешного развертывания:

1. **Откройте приложение:**
   - Amvera предоставит URL вашего приложения
   - Обычно выглядит как: `https://your-app-name.amvera.io`

2. **Проверьте функциональность:**
   - Загрузка Excel файлов
   - Расчет ставок
   - Сохранение данных в localStorage

## Важные моменты

### Почему выбираем "Приложение":
- Наш проект - это веб-приложение на Node.js
- Использует Express сервер для обслуживания статических файлов
- Не требует базы данных (использует localStorage браузера)
- Не является Cron Job или преднастроенным приложением

### Конфигурация в [`amvera.yml`](amvera.yml:1):
```yaml
name: logistics-calculator
services:
  web:
    build: .                    # Сборка из Dockerfile
    ports:
      - 3000:3001              # Внешний:3000 → Внутренний:3001
    environment:
      - NODE_ENV=production
      - PORT=3001
```

## Устранение проблем

Если возникли проблемы:

1. **Проверьте логи в Amvera Console**
2. **Убедитесь, что все файлы в репозитории:**
   - [`package.json`](package.json:1)
   - [`Dockerfile`](Dockerfile:1)
   - [`amvera.yml`](amvera.yml:1)
   - [`server.js`](server.js:1)

3. **Проверьте настройки портов:**
   - Внутренний порт приложения: 3001
   - Внешний порт Amvera: 3000
