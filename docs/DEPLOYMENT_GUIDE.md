**Для Mail.ru:**
- SMTP сервер: `smtp.mail.ru`
- Порт: `587`

### 3. Настройки базы данных PostgreSQL
Для работы системы требуется база данных PostgreSQL:

**Требования к базе данных:**
- PostgreSQL 12+
- Минимум 1GB дискового пространства
- Подключение по стандартному порту 5432

**Переменные окружения:**
```bash

JWT_SECRET=your-secret-key-change-in-production
```

## 📋 Процесс развертывания

### Шаг 1: Подготовка репозитория
```bash
# Убедитесь, что все файлы закоммичены
git add .
git commit -m "Подготовка к развертыванию"
git push origin main
```

### Шаг 2: Настройка Amvera
1. Войдите в [Amvera Cloud](https://cloud.amvera.ru)
2. Перейдите в проект `calculator-limslava`
3. Убедитесь, что конфигурация загружена из [`amvera.yml`](amvera.yml:1)

### Шаг 3: Настройка SMTP
После развертывания:
1. Откройте `https://calculator-limslava.amvera.io/`
2. Войдите как администратор (логин/пароль по умолчанию)
3. Перейдите в "Настройки Email" в панели администратора
4. Введите настройки SMTP
5. Протестируйте отправку

### Шаг 4: Настройка базы данных
1. Создайте базу данных PostgreSQL
2. Настройте переменные окружения в Amvera Console:
   - `DATABASE_URL` - строка подключения к PostgreSQL
   - `JWT_SECRET` - секретный ключ для JWT токенов
3. При первом запуске система автоматически создаст таблицы и начальные данные

### Шаг 5: Создание пользователей
1. В панели администратора нажмите "Добавить пользователя"
2. Введите email и выберите роль
3. Система автоматически сгенерирует пароль
4. Данные для входа будут отправлены на email пользователя

## 🛠️ Устранение неполадок

### Проблемы с базой данных:
- **Ошибка подключения к PostgreSQL:** Проверьте `DATABASE_URL` в переменных окружения
- **Таблицы не создаются:** Убедитесь, что у пользователя базы данных есть права на создание таблиц
- **Данные не загружаются:** Проверьте логи сервера на наличие ошибок SQL

### Если забыли пароль администратора:
1. Откройте `https://calculator-limslava.amvera.io/reset-admin.html`
2. Нажмите "Сбросить администратора"
3. Используйте данные по умолчанию

### Если не приходят email:
1. Проверьте настройки SMTP в панели администратора
2. Убедитесь, что пароль приложения правильный (для Gmail)
3. Проверьте спам-папку

### Если ссылка смены пароля не работает:
- Убедитесь, что email в ссылке точно соответствует email пользователя
- Проверьте, что пользователь существует в системе

### Если dropdown пустые:
- Проверьте подключение к базе данных
- Убедитесь, что данные загружены в таблицы
- Проверьте авторизацию пользователя (токен должен быть действительным)

## 🔧 Технические детали

### Конфигурация Amvera ([`amvera.yml`](amvera.yml:1))
```yaml
name: logistics-calculator
services:
  web:
    build: .
    ports:
      - 3000:3001    # Внешний порт:3000 → внутренний порт:3001
    environment:
      - NODE_ENV=production
      - PORT=3001
    resources:
      memory: 512Mi
      cpu: 500m
```

### Конфигурация Docker ([`Dockerfile`](Dockerfile:1))
- Базовый образ: Node.js 18 Alpine
- Рабочая директория: /app
- Пользователь: nextjs (безопасность)
- Порт: 3001

### Сервер ([`server.js`](server.js:1))
- Express сервер для статических файлов
- Настройки безопасности с Helmet
- Сжатие данных с Compression
- Content Security Policy
- Подключение к PostgreSQL через Sequelize ORM
- JWT аутентификация
- Автоматическая инициализация базы данных

## 🧪 Локальное тестирование

```bash
# Клонируйте репозиторий
git clone https://github.com/limslava/calculator
cd calculator

# Установите зависимости
npm install

# Настройте базу данных PostgreSQL
# Создайте файл .env с переменными окружения:
echo "DATABASE_URL=postgresql://username:password@localhost:5432/logistics_db" > .env
echo "JWT_SECRET=your-secret-key-change-in-production" >> .env

# Запустите сервер
npm start

# Откройте в браузере: http://localhost:3001
```

**Примечание:** При первом запуске система автоматически создаст таблицы и начальные данные.
