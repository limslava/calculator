# 🗄️ Настройка PostgreSQL для развертывания на Amvera

## Обзор

Amvera не предоставляет встроенную базу данных PostgreSQL, поэтому нужно использовать внешний сервис. Это руководство поможет выбрать провайдера и настроить подключение.

## 🎯 Быстрый выбор провайдера

### Для быстрого старта (рекомендуется)
**Supabase** - бесплатный тариф, простой интерфейс, русская документация

### Для продакшн использования
**Railway** или **Heroku Postgres** - надежные провайдеры с хорошей производительностью

### Для максимального контроля
**DigitalOcean** или **VPS** - полный контроль над сервером

## 📋 Пошаговое руководство для Supabase

### Шаг 1: Создание базы данных в Supabase

1. **Регистрация** на [supabase.com](https://supabase.com)
2. **Создание проекта**:
   - Нажмите "New Project"
   - Название: `logistics-calculator`
   - Пароль: сохраните его надежно
   - Регион: выбирайте ближайший к вашим пользователям
   - Нажмите "Create new project"

3. **Получение данных подключения**:
   - Перейдите в Settings → Database
   - Скопируйте строку подключения из раздела "Connection string"
   - Формат: `postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres`

### Шаг 2: Настройка Amvera

1. **В Amvera Console** перейдите в настройки проекта
2. **Добавьте переменные окружения**:
   ```
   DATABASE_URL=postgresql://postgres:ваш_пароль@db.ваш_проект.supabase.co:5432/postgres
   JWT_SECRET=ваш_секретный_ключ_для_jwt_токенов
   ```

### Шаг 3: Проверка подключения

После развертывания система автоматически:
- ✅ Создаст таблицы в базе данных
- ✅ Создаст администратора `admin@logistics.com`
- ✅ Инициализирует начальные данные

## 🔧 Альтернативные провайдеры

### Railway

1. **Регистрация** на [railway.app](https://railway.app)
2. **Создание PostgreSQL**:
   - Нажмите "New Project" → "Provision PostgreSQL"
3. **Получение строки подключения**:
   - Перейдите в Variables → `DATABASE_URL`

### Heroku Postgres

1. **Регистрация** на [heroku.com](https://heroku.com)
2. **Создание приложения**
3. **Добавление PostgreSQL**:
   ```bash
   heroku addons:create heroku-postgresql:hobby-dev
   ```
4. **Получение строки подключения**:
   ```bash
   heroku config:get DATABASE_URL
   ```

### DigitalOcean

1. **Регистрация** на [digitalocean.com](https://digitalocean.com)
2. **Создание PostgreSQL кластера**:
   - Managed Databases → Create Database Cluster
   - Выберите PostgreSQL
   - Регион: ближайший к пользователям
3. **Настройка подключения**:
   - Получите host, port, database, username, password
   - Формат строки: `postgresql://username:password@host:port/database`

## ⚙️ Настройка базы данных

### Требования к базе данных

- **PostgreSQL версия**: 12 или выше
- **Дисковое пространство**: минимум 1GB
- **Память**: минимум 1GB RAM
- **Подключения**: минимум 20 одновременных подключений

### Автоматическая инициализация

При первом запуске система автоматически выполнит:

```sql
-- Создание таблиц
CREATE TABLE IF NOT EXISTS "Users" (...);
CREATE TABLE IF NOT EXISTS "SeaData" (...);
CREATE TABLE IF NOT EXISTS "RailData" (...);
-- и т.д.

-- Создание администратора
INSERT INTO "Users" (email, password, role, isActive) 
VALUES ('admin@logistics.com', 'зашифрованный_пароль', 'admin', true);
```

## 🔐 Безопасность

### Рекомендуемые настройки

1. **JWT Secret**:
   ```bash
   # Сгенерируйте надежный секретный ключ
   openssl rand -base64 32
   ```

2. **Пароль базы данных**:
   - Минимум 16 символов
   - Буквы, цифры, специальные символы
   - Не используйте простые пароли

3. **Ограничение подключений**:
   - Настройте firewall для доступа только с IP Amvera
   - Используйте SSL подключения

## 🛠️ Устранение неполадок

### Ошибки подключения

**Проблема**: "Connection refused" или "Timeout"
**Решение**:
- Проверьте правильность строки подключения
- Убедитесь, что база данных запущена
- Проверьте настройки firewall

**Проблема**: "SSL required"
**Решение**:
- Убедитесь, что в `config/database.js` включен SSL для production

### Ошибки инициализации

**Проблема**: Таблицы не создаются
**Решение**:
- Проверьте права пользователя базы данных
- Убедитесь, что пользователь имеет права на создание таблиц

**Проблема**: Администратор не создается
**Решение**:
- Проверьте логи сервера на наличие ошибок
- Убедитесь, что email администратора уникален

## 📊 Мониторинг

### Проверка работоспособности

После развертывания проверьте:

1. **Подключение к базе**:
   ```bash
   # Используйте psql или pgAdmin для подключения
   psql $DATABASE_URL
   ```

2. **Таблицы созданы**:
   ```sql
   SELECT table_name FROM information_schema.tables 
   WHERE table_schema = 'public';
   ```

3. **Данные загружаются**:
   - Войдите как администратор
   - Загрузите тестовые Excel файлы
   - Проверьте, что данные сохраняются
