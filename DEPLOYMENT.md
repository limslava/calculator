# Инструкция по развертыванию на Amvera

## Подготовка проекта

Проект уже подготовлен для развертывания на Amvera. Созданы все необходимые файлы:

- [`package.json`](package.json:1) - конфигурация Node.js проекта
- [`server.js`](server.js:1) - Express сервер для статических файлов
- [`Dockerfile`](Dockerfile:1) - конфигурация Docker контейнера
- [`amvera.yml`](amvera.yml:1) - конфигурация Amvera
- [`.dockerignore`](.dockerignore:1) - исключения для Docker

## Шаги для развертывания

### 1. Подготовка репозитория

1. Создайте Git репозиторий для проекта
2. Загрузите все файлы проекта в репозиторий
3. Убедитесь, что все файлы находятся в корне репозитория

### 2. Развертывание на Amvera

1. **Войдите в Amvera Console:**
   - Перейдите на https://cloud.amvera.ru
   - Авторизуйтесь в системе

2. **Создайте новый проект:**
   - Нажмите "Создать проект"
   - Выберите "Из Git репозитория"
   - Укажите URL вашего Git репозитория

3. **Настройте конфигурацию:**
   - Amvera автоматически обнаружит [`amvera.yml`](amvera.yml:1)
   - Проверьте настройки в файле конфигурации:
     - Порт: 3001
     - Память: 512Mi
     - CPU: 500m

4. **Запустите развертывание:**
   - Нажмите "Deploy"
   - Дождитесь завершения сборки и развертывания

### 3. Проверка работоспособности

После успешного развертывания:

1. Откройте URL вашего приложения (будет предоставлен Amvera)
2. Проверьте функциональность:
   - Загрузка Excel файлов
   - Расчет ставок
   - Сохранение данных в localStorage

## Локальное тестирование

Перед развертыванием можно протестировать приложение локально:

```bash
# Установка зависимостей
npm install

# Запуск сервера
npm start

# Приложение будет доступно по адресу: http://localhost:3001
```

## Особенности приложения

### Архитектура
- **Клиентская часть:** HTML, CSS, JavaScript
- **Серверная часть:** Node.js + Express для статических файлов
- **Хранение данных:** localStorage браузера
- **Обработка Excel:** библиотека SheetJS (XLSX)

### Функциональность
- **Роли пользователей:** Закупщик и Менеджер по продажам
- **Типы перевозок:** Море, ЖД, Прямое ЖД, Прямое море, Море+ЖД
- **Формат данных:** Excel файлы с определенной структурой
- **Расчет ставок:** Автоматический поиск по параметрам

### Безопасность
- Используется Helmet для защиты заголовков
- Сжатие данных с помощью compression
- Content Security Policy настроен для безопасной работы

## Мониторинг и логи

После развертывания в Amvera Console доступны:
- Логи приложения
- Мониторинг ресурсов (CPU, память)
- Health checks
- Метрики производительности

## Обновление приложения

Для обновления приложения:
1. Внесите изменения в код
2. Загрузите изменения в Git репозиторий
3. Amvera автоматически пересоберет и развернет новую версию

## Технические требования

- **Node.js:** версия 18 или выше
- **Память:** минимум 512MB
- **Порты:** 3001 (внутренний), 3000 (внешний)
- **Браузеры:** Chrome 60+, Firefox 55+, Safari 12+, Edge 79+

## Устранение неполадок

Если приложение не запускается:
1. Проверьте логи в Amvera Console
2. Убедитесь, что все файлы загружены в репозиторий
3. Проверьте корректность [`amvera.yml`](amvera.yml:1)
4. Убедитесь, что порт 3001 доступен
